# M1.9 本地账号体系

服务端现在同时支持两种本地登录：

- 游客：沿用 `AccountSession → EntryReg → Account → fresh AccountSession → Auth`，设备绑定只保存 SHA-256，不保存设备原文。
- 用户名密码：`AccountSession(entry_type=password)` 后用 `EntryReg/Account` 注册，`Password` 登录，`PasswordReset` 改密，`ExistEntry` 查询，`AccountGuestBind` 将游客存档绑定到用户名。

密码只保存 scrypt 派生值和随机盐；账号、会话和访问 token 仍只写本地 SQLite。社交账号字段一律拒绝，服务端不连接 QQ、微信、Apple、Google 或真实支付。

当前 HTTP 层仍使用已有的 wireformat envelope；新登录界面/客户端补丁需要按此协议调用本地接口。相关回归覆盖注册、重复用户名、错误密码、改密、游客绑定和 token 有效期。
