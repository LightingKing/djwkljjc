## 登录和错误回包合同

缓存密码登录先取 `/AccountSession/`，再以 `Authorization: AccountToken <session token>` 调用
`POST /Auth/`，JSON 内容为：

```json
{"entryType":"password","username":"<cache.accountEntry>","accessToken":"<cache.accessToken>"}
```

`cache.accountEntry` 是上次成功输入的用户名（原 Auth.OnAccountAuthResponse 从 `accountAuth.entry` 保存），
不是服务器生成的 guest entry。缓存续期不发送密码，也不把密码写进 accountCache。
服务端必须验证用户名与 token 对应同一账号、token 未过期，成功返回原 Auth 字段
`accountId/openId/tokenAccess/createTime/expireSeconds`；本轮服务端将有效期设为 30 天。
客户端 token 已过期或缺失时直接要求密码输入，不尝试 MSDK。

guest 缓存仍发送原生 `ApiAuthInfo` wireformat，字段为 `entry=<guest entry>, entryType=guest`。
不同 locale 的缓存不发送到当前账号服务。服务端拒绝或网络失败均保留缓存；本次显示登录表单，
后续冷启动可再次尝试。缓存验证成功后停留在原开始界面，不自动跳过开始按钮。

A4 必须使用以下原生提示形式，**不要同时包含 error 字段**：

| 回包 | 原 `OnHandleRestifizerError` 行为 |
|---|---|
| HTTP 509，`{"notify":{"code":"WindowLogin_LoginFailed"}}` | `ShowHintText(message, 2)`，无 ResetGame |
| HTTP 507，`{"notify":{"code":"Window_FatalError"}}` | `ShowMessageOK(message)`，无重置回调 |
| HTTP 400，`{"error":{"code":"Error_LoginFaild"}}` | 弹窗确认后仍 ResetGame，不适合可预期拒绝 |

普通 notify 只放已有本地化 `code`，不填 `banReason`/`banTime`；后者是封禁说明分支。
`Error_ActivityNotStart` 若在 `error.code` 中会被原生直接忽略，在 `notify.code` 中正常显示。
客户端没有扩大吞掉全局 error/kick；仅本地登录失败回调明确返回 true。

## A17：旧 PatchCache 的清理方式

原路径证据见 `docs/热更新Lua通道.md:113/119/150`：下载 ZIP 存在
`persistentDataPath/PatchCache`；运行时加载的是解压后的 `persistentDataPath/Patch`。
已观测设备的 persistentDataPath 为 `/sdcard/Android/data/com.tencent.tmgp.fcicv/files`，
其他设备先读取实际路径，不把这个路径当作通用常量。

以下维护步骤在2026-11-02更新为按实际安装版本选择；上文v6构建与验收记录仍为历史证据。本批用户自行操作客户端，没有代为清理缓存。

1. 当前安装版本冷启动验收完成后退出应用，备份当前 `Patch`、`PatchCache` 和 `GameVersionInfo` 的一致快照。
2. 列出 `PatchCache` 中的文件，对照旧 v2/v3/v4 清单 URL 的 basename 与长度/摘要，确认具体旧 ZIP。
3. 先核对客户端 `GameVersionInfo` 实际补丁号、对应发布的 `patch-manifest.json` 和 `build-report.json`，按 URL 文件名、长度、CRC/SHA256确定当前 ZIP。只移走已确认被替代的旧ZIP到备份目录，保留实际安装版本对应ZIP和未识别文件，不再写死保留v6。版本或摘要不一致时先停止清理。
4. 不移动 `Patch/assetbundle`，不修改或单独回退 `GameVersionInfo`。冷启动确认补丁号未变、无重复ZIP请求后再决定是否删除备份。

本轮没有执行缓存清理。回滚应恢复完整一致的客户端快照，或把旧源码作为更高版本补丁交付；
切回 v5 manifest 不会自动降级已安装的 v6。
