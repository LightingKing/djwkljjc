# M5 网页活动与小游戏沙盒

本地服务现在为公告状态、网页投票、分享、拼图、明信片和抓娃娃保留了持久化兼容接口。状态与账号存档使用同一个 SQLite/WAL 数据库；重复读标记、分享奖励和小游戏奖励不会重复发放。网页投票使用固定的本地角色列表和本地票券，投票结果只对当前本地账号和本机可见。

由于 `playeraction.proto`、`vote.proto` 的原始描述符语法字段损坏，涉及玩家资料、公告状态和网页投票的返回值在缺少可验证 protobuf 类型时使用同字段名的 JSON envelope；不会猜测损坏描述符中的字段。`collections.proto`、`notepad.proto` 等可解析消息仍使用原始 protobuf 类型。

已提供的本地路由包括：

- `/fci/notice/*`：读、分享、奖励领取状态；
- `/fci/webvote/*`、`/fci/voterole/*`：角色列表、票券、投票和汇总；
- `/fci/jigsawpuzzle/*`、`/fci/postcard/*`、`/fci/clawcrane/*`：进入、点亮、领取或抽取；
- `/fci/share/`：按服务器时钟每周一次本地分享奖励，跨重启保存，跨周后自动恢复可领取状态。

这些路由不访问官方公告、投票、支付或社交服务，奖励走本地资源账本，便于重启和回归测试。
