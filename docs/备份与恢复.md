# 存档备份与恢复

`tools/backup_restore.py` 使用 SQLite backup API 创建一致性快照，并在恢复前执行 `PRAGMA integrity_check`。目标文件会通过临时文件原子替换，源库和源备份不会被修改。

```powershell
python .\tools\backup_restore.py backup `
  --database .\state\local.sqlite3 `
  --destination .\backups\local-2026-10-28.sqlite3

python .\tools\backup_restore.py restore `
  --source .\backups\local-2026-10-28.sqlite3 `
  --destination .\state\local-restored.sqlite3
```

服务端默认把账号、游戏和经济状态写入 `state/local.sqlite3`，上面的命令即可备份默认状态。若通过直接模块调用或显式配置继续使用旧的 `accounts.sqlite3`、`game.sqlite3` 和 `economy.sqlite3`，应分别备份这些文件；兼容层不会自动把旧库数据复制到统一库。工具不会删除原文件，也不会执行 `pm clear` 或清理客户端数据。
