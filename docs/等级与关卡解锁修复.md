# 玩家等级 / 关卡逐个解锁 / 编队 修复(2026-10-29)

## 问题
1. 打关给了经验但不升级 → 功能(按等级解锁的窗口)无法开放。
2. 剧情/关卡一次性全部解锁,原版应逐个解锁。
3. 战斗准备(编队)界面空白,没有队员。

## 根因
- 服务端的配置表是**运行时部分抓取**:PlayerLevelInitConfig 只有 6/99 行,DungeonReward 3/683 行。
- 等级规则是占位:每级固定 1000 经验、经验按累计存;每关经验是占位值(剧情 100、普通 20)。
  客户端则按 PlayerLevelInitConfig 的**每级增量**(Lv2=1, Lv3–8=6, Lv9–15=12 …)判定,经验存的是**当前级内进度**。
- 解锁只按章节:章节一开,章内所有关卡都 `unlocked=True`。
- `/fci/ActorGroup/` 是写死的 `{}`;`/fci/SelectedGroupId/StoryMode` 没有处理(501)。
  编队窗口要先拿到选中队伍编号才去拉队伍,再读 `groups[id].members` → `m_groups` 为 nil → 空白。

## 修复
- `tools/export_client_tables.py`:把客户端 APK 自带的完整配置表(解密+反编译后的 `xlsx__*.lua`,纯数据)
  在隔离的 Lua 5.3 中求值导出为 JSON → `data/client-tables/`(PlayerLevelInitConfig 99 行、DungeonReward 683 行、ChapterInfo 35 行,带来源与 SHA-256)。
- `dungeon.py`:
  - 等级:按客户端表滚动升级(`_roll_player_level`),经验存级内余量;升级发放 `levelReward`(按新等级 `incInfo.limit` 封顶)。
  - 每关玩家经验 = 消耗体力(`cost` + 胜利 `costWin`,资源类型 6)。依据:普通关 1+5=6 体力,Lv3–8 每级正好 6 经验;首个剧情战 1 体力 → Lv2 需 1。
    (DungeonReward 没有玩家经验字段,这是根据等级表与体力的完全吻合做的推断,已在代码注释注明。)
  - 结算消息 `resChange` 中经验的 `count` = 战前 + 获得(未滚动值),客户端会自己减去所跨等级的阈值做动画。
  - 关卡解锁:使用客户端 `DungeonReward.preDungeonId`(2011→2012→2013→1→2→…→8→2021…,训练 5001 需 4)。
    前置关是本服未暴露的节点(如第 2 章剧情 2021–2023)时沿链回溯,避免卡死;已通关的关卡保持开放。
- `systems.py`:实现 `/fci/ActorGroup/`(GET/PUT,5 套预设 = `Misc.maxActorGroup`,每套 6 槽,索引 0–2 主、3–5 助战;默认 1 号位为初始角色 uid 1)
  与 `/fci/SelectedGroupId/<mode>`(GET/PATCH,按模式分别保存)。
- `tools/migrate_player_exp.py`:按新规则用战斗记录重算旧存档等级/经验(player01:Lv1 210 → Lv2 1,已备份)。
- `server.py`:`/clientupdate/` 热更新覆盖改为显式参数 `--force-patch PATH`(原先写死仓库路径,测试会读到真实文件)。
- 测试:新增 `tests/test_progression.py`、`tests/test_actor_groups.py`;更新 `tests/test_dungeon.py` 中旧占位经验断言。全套 233 通过。

## 模拟器卸载重装流程(2026-10-30 实测)
1. `adb uninstall com.tencent.tmgp.fcicv`;`adb install -g runtime/installed-base.apk`(与之前安装的 APK 字节相同)。
2. 重装后应用 uid 会变(10170→10171)。`prepare-avd.ps1` 会因 `LJJC_LOCAL` 链里残留旧 uid 规则而拒绝执行:确认规则只是旧 uid 的 ACCEPT 19080/9102 + REJECT 后,`iptables -F LJJC_LOCAL` / `ip6tables -F LJJC_LOCAL` 再重跑脚本。
3. **Mono 受信 CA 必须重装**（卸载会删掉）：将新 CA `analysis/ljjc-local/certs/new-20261103/ca.pem` 转为 DER，安装文件名必须为 `4F2AF6478AB96825ABC77F2FCE9AE5BD487E29B9.cer`（当前 `runtime/ljjc-ca.der` 已是该新 CA；Mono X509Store 只读 `*.cer`），放到 `/data/data/com.tencent.tmgp.fcicv/files/.config/.mono/certs/Trust/`（Mono 的 HOME 是 files；另放 `/data/data/<pkg>/.config/...` 无害），chown 为应用 uid 并 restorecon。旧 CA 可暂时保留。否则 bootstrap 报 `Invalid certificate received from server`，界面“网络连接失败”。
4. 启动:安卓"旧版本应用"提示点 OK → 补丁 v2"立即更新" → 腾讯用户协议"同意" → 账号密码登录。
