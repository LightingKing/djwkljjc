## 第五轮本地商品规则（2026-11-03）

- `6480 元 / 64800 迷子` 与 `64800 元 / 648000 迷子` 是本地沙盒商品，只能通过 `data/local-sandbox-products.json` 和客户端本地补丁暴露；它们不写入标注为原版 APK 来源的 `data/client-tables/PurchaseInfo.json`。
- 两档商品使用 `LOCAL_SANDBOX` 一次性订单令牌结算，不连接真实支付平台。价格、数量和首充双倍行为是本地规则；自动化测试通过，原生界面和实机状态仍待用户验收。
- 服务端证书距到期少于 30 天时，启动日志和 `/health` 标记 warning；这是运维规则，不是原版客户端数据。当前 CA 私钥未在工作区找到，续签保持待补私钥状态。
- 组队副本（`dungeonType=10`）胜利固定发放季节糖果 1016，受本期战斗上限 750 约束；失败和重复结算不发。该发放是本地玩法补全，不能当作原版掉落表证据。
- 角色返礼沿用 `Misc.rolePresentMaxNum` 的每日账号上限（当前原表值为 3）。达到上限后列表和红点都返回空，北京时间 06:00 后重置；仅自动化通过，原生界面待用户验收。
- 主题任务 60002–60005 的混合参数按客户端 `ActorInfo` 角色 ID 与关卡 ID 分开解释；角色条件要求本次队伍有交集，关卡条件要求本次关卡命中。这是按客户端任务参数修正的服务端判定。
- 客户端 IAP 本地适配统一使用 `client-patch/hot-update/sources/iaphandler-local.lua`，仅在回环或 RFC1918 地址且端口属于本服务端口时启用；LAN 与正式候选清单共用同一源码。补丁构建只做离线候选，原版签名 APK、TSS 和完整性保护不改变。
