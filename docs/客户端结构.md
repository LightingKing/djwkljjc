## 通信通道

已在运行日志中确认的本地联调路径：

1. 引导：`/pr2new_djwk.json`。
2. 目录：`/dirsvr/Dir`、`/dirsvr/DirAccount`；服务端根据 [server.toml](../server.toml) 动态改写地址。
3. 账号：`/AccountSession/`、`/EntryReg/`、`/Account/`、`/Auth/`，登录后使用 `Authorization: Token <local_access_token>`。
4. 游戏 REST：`/fci/*`，按描述符返回 wireformat envelope。
5. 推送：`/push` WebSocket，处理 `CsConnect`、`CsHeartbeat`、`CsLogin` 和本地登录初始化推送。
6. TLS：服务端提供可选 TLS 监听；客户端补丁的信任配置和 Unity/C# 通道仍需要在真实 APK 上回归确认。能走 HTTP 的本地通道优先使用 HTTP。

## 已知客户端边界

- `data/descriptor_set.pb` 能提供登录、章节、战斗和部分活动消息的类型描述；契约清单当前有 84 个观察到的描述符接口，不能等同于 ROADMAP 计划的全部 342 个 Api + 66 个 Cs/Sc。
- `data/config/` 中 `observedCount > rowCount` 的表只是部分运行时样本，不能作为全量配置。
- 目前没有从 IL2CPP 生成可编译 C# 工程；REA/Il2CppDumper 只能作为结构取证工具。
- Android 11 x86 的可重复闪退发生在系统 `MediaPlayer`/`libmedia.so` 路径，服务端登录链路已经成功，详见 [客户端稳定性.md](客户端稳定性.md)。
