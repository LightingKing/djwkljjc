# 本机管理面板与备份

服务启动后，管理面板只接受 `127.0.0.1`/`::1` 请求：

```text
http://127.0.0.1:19080/__local__/admin
```

面板和 JSON 接口提供：

- `/__local__/admin/status`：服务器时间偏移、账号数量、推送会话数、接口覆盖率和最近日志；
- `/__local__/admin/accounts`：脱敏账号列表；
- `/__local__/admin/accounts/<id>/reset-password`：重置本地账号密码并撤销旧会话；
- `/__local__/admin/accounts/<id>/revoke-sessions`：撤销账号会话；
- `/__local__/admin/payments`：只读查看沙盒发货记录、充值汇总和待确认订单数量；不返回支付 token 或平台回执；
- `/__local__/admin/clock`：读取或设置时间偏移，便于验证每日/每周重置；
- `/__local__/admin/backup`、`/__local__/admin/backups`：创建和查看 SQLite 在线备份；
- `/__local__/admin/restore`：从已列出的备份目录回档，完成后建议重启服务；
- `/__local__/admin/logs`：读取最近的安全审计日志行。
- `/__local__/admin/crash-logs`：读取本地崩溃报告索引（不返回正文）。
- `/__local__/admin/activity-schedule`：查看或调整活动排期锚点。
- `/__local__/admin/activities`、`/activities/<id>`：维护本地活动阶段的增删改查。

启动脚本会在服务初始化完成后自动备份 `accounts.sqlite3`、`game.sqlite3`、`economy.sqlite3` 和统一库 `local.sqlite3` 中实际存在的文件，并按 `server.toml` 的 `backup_retention` 保留最近的备份。SQLite 备份通过在线备份 API 生成，包含 WAL 中已经提交的数据。

管理接口没有改数值或注入任意路径的能力。回档只接受时间戳格式的备份目录名，并且只处理上述固定数据库文件。

客户端崩溃日志通过 `POST /__local__/crash-log`、`/fci/crash-log` 或 `/bugly/crash-report` 写入 `state/crash-logs/YYYY-MM-DD/`。报告大小有上限，JSON 中常见的 token、密码和 cookie 字段会在落盘前替换为 `<redacted>`；原始 APK 不会向 Bugly 或其它官方服务上报。

每日备份守护线程每分钟检查一次服务器时钟日期，每个日期最多生成一份备份，并复用同一个保留数量和管理员锁。启动时备份与管理员手动备份仍可单独执行。

`JsonlLogger` 在 UTC 日期变化时把上一日的文件归档为 `requests.YYYY-MM-DD.jsonl`，随后继续写入主日志路径；日志内容仍然只保留脱敏后的请求元数据和哈希。
