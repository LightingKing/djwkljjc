# 未注册契约与安全边界

当前 `contracts/api.yaml` 有 84 条接口，运行中的 `FixtureServer` 注册了 68 条本地处理接口。剩余 16 条保持明确的 `501 route_not_implemented`，不会用假成功响应掩盖缺失实现。

这些接口属于服务端管理、外部身份或外部系统集成，不能为了提高覆盖率而伪造：

- GM 密码、GM 账号入口、删除玩家、封号、功能封停、踢人、踢全体、关服、清理缓存；
- LDAP 认证、BBrr 外部账号导入；
- WhiteOpenId 白名单增删改；
- 修改服务端时间。

`/AccountEntry/bind-bbrr-old/` 是唯一保留的旧迁移兼容入口，但它只接受本地 `Token` 或 `AccountToken`，返回脱敏的本地账号记录并标记 `sandbox: true`。它不会连接、导入或合并外部身份；缺少有效令牌返回 `401`。

服务端本地管理页已经提供受限的时间偏移、备份、活动排期、覆盖率和沙盒账单能力。管理接口只监听回环地址，不能通过客户端契约调用危险操作。

验证：

```powershell
python -m pytest -q tests/test_safe_contract_completion.py
```

安全契约补全测试覆盖令牌校验和路由匹配；全量回归结果记录在 `README.md` 和 `ROADMAP.md`。
