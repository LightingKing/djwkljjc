# M6 本地机器人、社交与异步 PVP

当前实现是离线兼容子集，使用固定随机种子生成 24 个机器人。机器人不会访问官方账号或远程服务，好友、聊天、助战、异步 PVP 和排行榜状态保存在 `local_social_state`。机器人快照按服务器时钟每 7 天缓慢增加等级和积分（本地上限 60/3000），因此长期运行会有可重复的成长，而不会随着任意时钟跳跃无限增长。

已覆盖：

- 好友列表、推荐、申请、召回、屏蔽和点赞；新账号预置两个本地机器人，便于助战页面有内容。被屏蔽的机器人不会出现在推荐或助战列表，也不能再次申请。
- 聊天、弹幕、最近联系人；新账号预置两条带 `localBot` 标记的本地弹幕，消息限制为 128 个字符并保留最近 100 条，消息 ID 在滚动保留后仍保持递增。
- 助战列表返回好友机器人阵容。
- 异步 PVP 匹配、结算、战绩和积分；默认初始积分 1000，胜负只影响本地积分；匹配票据和结算结果跨重启持久化，重复请求不会重复加分或发奖。
- 排行榜把当前玩家和固定机器人按本地积分排序。
- 公会页面提供本地单公会的加入、捐献、技能、租借、记录和公会副本流程；捐献会经过资源账本并持久化。
- 公会自动填充 5 个固定种子机器人，支持 JSON roster/summary、邀请/踢出、会长投票与转让、助战请求/领取、阶段结算和个人副本记录；所有变更幂等并跨重启保存。

机器人等级、头像、阵容和积分属于本地沙盒规则，固定种子为 `20261028`，用于重启后保持确定性。社交 JSON 状态的读改写由 `storage.compat.shared_process_lock` 使用数据库旁路锁串行化，因此多个本地服务进程同时写入聊天、好友或异步 PVP 时不会互相覆盖；`tests/test_cross_process_state.py` 用 8 个独立 worker 回归社交写入，并用 5 个独立 worker 回归实时匹配幂等。该锁只解决同机本地 worker 的一致性，不提供跨机器网络同步。

跨进程真实玩家协作和官方实时服务仍未恢复；实时 PVP 已提供本地 RacePVP/BurstLink 机器人兼容子集，官方排行榜数据也未恢复。
