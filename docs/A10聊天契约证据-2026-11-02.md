# A10 聊天契约证据（2026-11-02）

本轮修正私聊会话归属、本人消息回包和在线低频机器人接线。以下是原始客户端代码证据与临时数据库验证，不代表用户实机验收。

## 原始模块恢复

- 原输入：`analysis/lua/window__chatroom__chatroom.luac`，40,677字节，SHA256 `2628a4304ea393ebcedb68451c02193398d80e487e9693f0522163fd9394c0ef`。
- 旧反编译失败是一个扩展长度字符串造成：FCI的`0xff`之后长度为uint32；给unluac补的标准头要求uint64。临时canonical输入偏移11432处为`ff 87 01 00 00`，随后直接为字符串字节；旧工具把接下来的四个文本字节也当作长度而越界。
- [复现脚本](../tools/decompile_chatroom_source.py)沿完整Lua函数结构读取，只在临时副本将这个长度扩为uint64，再使用已有FCI opcode map与unluac。输入未改，未重写游戏客户端。
- 输出79个函数、1个扩展字符串；`runtime/chatroom-a10-source.lua` SHA256 `4e256cd1201f5bbc41e7e705ed5fe6330f30939881405128f82bee244b21c94a`。

从`local-server/ljjc`执行：

```powershell
python tools/decompile_chatroom_source.py I:/workspace/mobilegame/runtime/chatroom-a10-source.lua
```
