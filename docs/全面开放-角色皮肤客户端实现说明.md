# 全面开放：角色与皮肤客户端实现记录

本记录覆盖第二批客户端分支；发布版本、最终提交和全量测试统一见《整改执行记录-2026-11-04-全面开放》。本页的资源存在性、Lua 执行和编译结果都是**仅自动化 / 待用户验收**。

## 开放边界与出处

- 开放角色 1409、2015、1017、1509、2127、2133。客户端 `ActorConfig` 的原有 `openTime` 已为 2018 或 2020，本批不修改它；`actorutil-content-open.lua` 增加本地白名单和禁用名单分支，仍保留原有角色表、Role 表和远端开放时间判断。
- 1501、1503、1505、1506、1515、1516、1517、1601、1607、2018、2106、2115、2016、2017 因核心 UI 或主动技能缺失不开放；1511 缺两个主动槽，2134 缺语音且 prefab 为占位，同样不开放。详见精确资源盘点，不能用替换整个人物资源的办法开放。
- 本地皮肤白名单来自 `data/server-only/content-open-20261104.json`，与服务端同一名单：未来皮肤 199 条中开放 195 条。只把白名单中 `openTime` 的原值 2029 改为 `2018-1-1 00:00:00`；每条修改前都有原值注释。442 条原行全部保留，价格、碎片、调色板、角色和来源字段逐值不变。
- `113401/113402/113403/113405` 仅属于不可开放的 2134，保留原时间。`113404` 本来就是 2018 年条目，不属于 199 条未来皮肤；原行不改，客户端按不可用角色过滤。混合角色皮肤也不能通过 `ignoreActorOpenTime` 暴露 2017 等不可用变体。
- 原始表及 Lua 字段是 A 级证据，精确资源包存在性是 C 级证据；提前时间、白名单和缺图替代策略为 D / 本地规则。角色获取与皮肤兑换由服务端交易实现负责，本模块不发放资源。
