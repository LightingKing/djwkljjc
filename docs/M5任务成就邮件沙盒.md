# M5 任务、成就与邮件（本地沙盒）

本阶段把启动后会影响主城红点和功能入口的任务、成就、邮件状态接入本地 SQLite。这里记录的是可玩的离线兼容子集，不能视为官方服务端数据或官方奖励规则。

## 当前行为

- `GET /fci/task/` 返回带 `res`、进度、截止时间和完成状态的本地任务；`POST /fci/task/` 领取一次本地金币，重复提交返回成功但不重复发放。
- `GET /fci/achievementsummary/` 和 `POST /fci/achievementreward/` 使用恢复到的描述符响应；奖励状态保存在 `local_event_state`，奖励是本地沙盒金币。
- `GET /fci/mail/` 和 `GET /fci/mail/<id>/` 返回本地邮件及附件。新本地账号有一封测试邮件，附件为 100 金币。
- `POST /fci/mail/obtain/` 或 `/collect/` 通过统一资源账本发放附件、标记已领取并设置已读；重复请求是幂等空操作。删除邮件只删除本地元数据，未领取附件不会转移到其他邮件。
- `POST /fci/subscribe` 保存本地订阅偏好：`opType=0` 查询、`1` 订阅、`2` 退订；返回 `ApiSubscribe.result`，状态按账号持久化且不调用 QQ/微信 SDK。
- `GET/POST /fci/websignin` 提供网页签到的本地兼容入口。`GET` 返回签到奖励、累计天数和 7 日目标，`POST` 每日幂等发放 50 金币，第 7 天额外发放一次 200 金币里程碑。原始 `vote.proto` 的 `ApiWebSignin` 描述符因语法损坏未加载，因此该入口返回带 `sandbox` 标记的 JSON；不会伪造官方活动表或奖励。
- 所有状态按账号保存在 `local_system_state` 或 `local_event_state`，服务端重启后仍保留；没有官方账号、远程邮件、推送或真实支付调用。

## 验证

在 `local-server/ljjc` 目录执行：

```powershell
python -m unittest discover -s tests -p 'test_systems.py' -q
python -m unittest discover -s tests -q
python -m compileall -q .
```

专项测试覆盖邮件列表/详情、附件领取、资源账本增量、重复领取不重复发放，以及重启后的领取状态。完整测试通过后仍需在客户端上逐项打开邮件、任务和成就面板做 UI 验收。

## 边界

任务和成就配置、奖励数值、邮件正文均为本地兼容数据。APK 中没有恢复出的官方表格或热更新内容不在此阶段伪造；未知接口继续按路线图标记并返回 501。
