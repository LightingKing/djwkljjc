## 实机探测

ADB server `5038` 能看到序列号 `HRBDFUN`，但设备在读取 `getprop` 时反复关闭 shell；目前没有拿到可靠的
`ro.product.cpu.abilist`、`ro.product.cpu.abilist32` 或 `ro.dalvik.vm.native.bridge` 结果。不能据此判断手机是否带
32 位转译器，也没有在实机上安装原版 APK。

重复探测命令：

```powershell
$adb = 'C:\Users\Administrator\AppData\Local\Android\Sdk\platform-tools\adb.exe'
& $adb -P 5038 -s HRBDFUN shell getprop
```
