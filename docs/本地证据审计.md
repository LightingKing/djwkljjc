# 本地兼容证据审计

路线图同时保留两种不同的接口证据：

1. `analysis/route-coverage.json` 来自本地游戏服务的 `RouteRegistry`，表示已注册的业务处理器数量。
2. `dev/contract-smoke-report.json` 来自隔离的契约 harness，故意不注册业务处理器，用于确认 84 条已知路由在缺少实现时返回安全的 `501 route_not_implemented`，不泄露 traceback，也不把未知路径误报成 404。

两者不能合并成一个“恢复率”。`tools/audit_local_evidence.py` 会读取 `contracts/api.yaml`、两份 JSON 报告，核对接口总数、名称集合、实现/未实现计数以及 501 响应安全性，生成 `analysis/local-evidence-audit.json`。

运行：

```powershell
python tools/audit_local_evidence.py
```

当前报告应同时显示本地处理器覆盖率和契约安全探针结果。安全探针全部通过只证明未实现接口有明确边界，不代表官方服务端已经恢复。
