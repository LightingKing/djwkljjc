# 本地活动页面（M5.7）

服务端提供一个完全离线的活动排期页面：

- `GET /__local__/activity`：内嵌 CSS/JavaScript 的本地活动控制台；
- `GET /__local__/activity.json`：当前排期、周期日、活动是否开放的 JSON；
- 两个地址只接受 `127.0.0.1` 或 `::1`，服务端绑定到局域网时也不会把管理页面暴露给手机上的其它应用；
- 页面不加载 CDN、图片或其它远程资源，断开外网仍可使用；
- 活动数据由 `ActivitySchedule` 读取，修改仍通过 `/__local__/admin/activities` 和 `/__local__/admin/activity-schedule` 完成。

签到、活动领取、商城和抽卡继续走本地 `/fci/` 兼容接口。页面只负责观察排期，避免 WebView 加载时产生意外发奖或修改存档。
