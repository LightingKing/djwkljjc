# 本地玩法烟测

`dev/local_playability_smoke.py` 在临时 SQLite 目录创建本地游客账号，按真实 `LocalGame.handle_http` 分发路径依次检查：

- 账号和主线 2011 副本结算；
- 角色升级、装备强化；
- 商城、沙盒代金券和本地下单/发货；
- 活动、签到、任务、邮件、抽卡；
- 好友、聊天、异步 PVP、排行榜、公会机器人；
- RacePVP 回合顺序、结算幂等和重启持久化。

运行：

```powershell
python dev/local_playability_smoke.py --output runtime/local-playability-smoke.json
```

脚本只连接临时本地数据库，真实支付、官方账号、远程服务和原 APK 都不会被访问。每个步骤要求 HTTP/业务状态成功；重复签到、邮件、代金券、副本和 PVP 结算还会检查幂等结果。报告的 `scope` 明确表示它只覆盖本地 M4–M6 兼容子集，不能证明完整官方内容、跨机器真人协作或 Android 客户端 G1/TPShell 已恢复。

对应回归测试为 `tests/test_local_playability_smoke.py`。路线图验收矩阵引用该报告作为本地玩法的动态证据。
