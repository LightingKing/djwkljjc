# 服务端独有数值

这里仅放本地服务端必须拥有、但无法从原始客户端完整确认的规则。每个文件都带有 `provenance` 和可信度：

- `A`：官方公告或可验证的历史记录；
- `B`：多个独立来源一致；
- `C`：单一运行时样本或本地实现推断；
- `D`：为离线可玩性设置的临时规则。

当前 `economy.yaml` 主要来自已抽取的客户端运行时样本，`activity-schedule.yaml` 是离线循环排期，`special-dungeons.yaml` 是金币本/爬塔/迷宫/锦标赛 PvE 的本地阶段规则，`historical-evidence.yaml` 只索引公开历史资料。它们不会被描述为完整官方历史数据；证据索引也不会自动改变运行时规则。
